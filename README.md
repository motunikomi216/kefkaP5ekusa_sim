# 混沌の終末トレーナー 3D

ファイナルファンタジーXIV「絶妖星乱舞」P5の「混沌の終末（エクサ）」を、ブラウザで繰り返し練習するための非公式ファンメイドツールです。

## 遊び方

`index.html` をブラウザで開くだけで動きます。インストールは不要です。PC向けです。

| 操作 | キーボード・マウス | コントローラー |
| --- | --- | --- |
| 移動（スタンダード） | `W` `A` `S` `D` | 左スティック |
| カメラ回転 | 右ドラッグ | 右スティック |
| ズーム | ホイール | 十字キー上下 |
| 開始・リトライ | `Space` | ×／A または OPTIONS／START |
| 中断 | `Esc` | ― |

- 北西から始まり、北西・北東から交互に来るエクサを避けます
- 通常モードは6本＋「終末の渦」の散開まで。エンドレスモードは被弾するまで続きます
- エクサの速度・大きさ・タイミング、カメラ、マーカーなどは画面上で調整でき、設定は5つまで保存できます（保存先は各自のブラウザ内です）
