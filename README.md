# 混沌の終末トレーナー 3D

ファイナルファンタジーXIV「絶妖星乱舞（絶ケフカ）」P5の「混沌の終末（エクサ）」を、ブラウザで繰り返し練習できる非公式の3Dシミュレーターです。

**▶ 遊ぶ：https://motunikomi216.github.io/kefkaP5ekusa_sim/**

## 動作環境

- 推奨：Windows ＋ Chrome 最新版
- PC専用です（スマートフォンには対応していません）
- コントローラーは PS5 コントローラー（DualSense）で動作確認しています

## 操作

| 操作 | キーボード・マウス | コントローラー |
| --- | --- | --- |
| 移動（スタンダード） | `W` `A` `S` `D` | 左スティック |
| カメラ回転 | マウス右ドラッグ | 右スティック |
| ズーム | マウスホイール | 十字キー上下 |
| 前進 | マウス左右同時押し | ― |
| 開始・リトライ | `Space` | ×／A または OPTIONS／START |
| 中断 | `Esc` | ― |

コントローラーは、ページを開いたあとにボタンを一度押すと認識されます。

## 内容

- エクサは北西から始まり、北西・北東から交互に来ます
- **通常モード**：6本のエクサのあと、「終末の渦」の散開まで
- **エンドレスモード**：被弾するまでエクサが来続けます。クリア本数の自己ベストを記録します
- 当たり判定は、実際のズレ（見た目より早く被弾する）を再現するため、エクサの見た目より2発ほど先にあります。「エクサ調整」の「当たり判定の先行」で変更できます（0で見た目どおり）

## 調整と保存

画面上のパネルから、次のような項目を調整できます。

- エクサ：爆発の大きさ、間隔、回数、予兆の時間、次のエクサが始まるタイミング、当たり判定の先行 など
- カメラ：初期の向き・角度・距離、注視点の高さ、視野角、ズーム範囲
- マーカー・自機・ボス：位置や大きさ、自機の移動速度
- 表示・演出：方角バー、ミニマップ、レーン線、効果音、画面の揺れ など

設定は「Save01〜Save05」に5つまで保存できます。設定と保存内容は各自のブラウザ内に保存され、サーバーには送信されません。各パネルは見出しをクリックするとたためます。

エクサのサイズやスピードは実際の様子を目視して合わせたもので、本番とは多少ズレがあります。気になる場合は各自で調整してください。
